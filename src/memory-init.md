## Objective

Create or update the `memory.md` file only when there is a structural change in the project.

It is also responsible for initializing the `.agents/memory/` structure when it does not exist.

---

## Step 0 — Memory Bootstrap (CRITICAL)

Check if the `.agents/memory/` directory exists.

---

### If it DOES NOT exist:

Request confirmation:

> The `.agents/memory/` directory does not exist. Do you want to create the project's base memory structure?

---

### If confirmed:

Create:

- `.agents/memory/memory.md`
- `.agents/memory/session-memory.md`
- `.agents/memory/decisions.md`
- `.agents/memory/quality-metrics.md`
- `.agents/memory/decision-suggestions.md`

## Step 1 — Change Classification

### Structural change (ALLOWED)

- Stack change
- Architecture change
- Domain change
- Structural reorganization

---

### Incremental change (LOCKED)

- Components
- Features
- Bugfix
- Refactoring
- Visual adjustments

---

## Blocking rule

If incremental change:

- DO NOT update memory.md
- BLOCK execution

---

## Step 2 — Validation of need

Compare current state with `memory.md`

Question:

> memory.md still represents the project?

---

### If YES:

- DO NOT update
- BLOCK

---

### If NO:

- Continue
